KIRBYVILLE KIRBYS APP (PWA)

To install on your phone, host this folder on HTTPS (e.g., GitHub Pages). Open the URL in Chrome/Edge on Android or Safari on iPhone, then use Install App or Add to Home Screen.

Opening index.html directly from the ZIP or a local file shows the website but cannot install the app or enable offline caching.

Keep index.html, sw.js, manifest.webmanifest and assets/ together when uploading.
